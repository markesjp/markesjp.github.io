# João Pedro Marques — Portfólio

[Acessar o portfólio](https://markesjp.github.io)

Portfólio profissional em português, com projetos, trajetória, tecnologias e contato. O currículo está em `curriculo.html` e pode ser salvo em PDF pelo navegador.

Site estático em HTML e CSS. Para editar, altere `index.html`, `styles.css` ou `curriculo.html` e envie as mudanças para `main`. A publicação é feita pelo GitHub Pages.

Os projetos destacados são LinguaFlow AI, a pesquisa de segmentação de núcleos e o analisador léxico Lumen. As experiências corporativas são apresentadas separadamente, com números de escala referentes às plataformas.
