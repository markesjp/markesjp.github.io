02
Pesquisa acadêmica · UFU

Visão computacional
para pesquisa biológica

Pipeline para segmentação de núcleos em embriões de Drosophila melanogaster. O método usa análise de contornos, detecção de concavidades e cortes geométricos para separar núcleos aderidos.

  • Python
  • OpenCV
  • NumPy
  • Processamento de imagens
Como o método funciona

Receitas JSON configuram o pré-processamento. A análise geométrica orienta a separação de instâncias, com interfaces gráficas para calibração e processamento em lote.

A avaliação compara as predições com anotações manuais, usando Dice/F1 de massa, F1 por instância e inspeção visual dos resultados.
